# Guide utilisateur — KUMBA Business

## Démarrer
1. Ouvrez l’application.
2. Choisissez **Créer mon commerce** ou **Démonstration**.
3. Mémorisez votre **PIN (4 chiffres)**.

## Vendre
1. Appuyez sur le bouton central **panier**.
2. Touchez un produit pour l’ajouter.
3. **Encaisser** → choisissez le moyen (espèces, MoMo, crédit…).
4. Validez. Le reçu s’affiche — partagez-le par WhatsApp ou SMS.

## Dettes
- Une vente non totalement payée avec un client crée une dette.
- **Plus → Dettes** pour voir qui doit combien.
- Ouvrez le client → **Encaisser**.

## Stock
- **Stock** : quantités et alertes.
- **Inventaire** : comptez, puis validez pour ajuster.

## Sauvegarder
**Plus → Sauvegardes → Créer** — gardez le fichier `.kumba` hors du téléphone.

## Hors ligne
Toutes les ventes, dettes, dépenses et stocks fonctionnent sans Internet. Un bandeau indique le mode hors ligne.
